# WarisanKU - Penghitung Warisan Berdasarkan Hukum Islam Berbasis Android

Aplikasi mobile Android untuk menghitung pembagian harta warisan secara akurat dan transparan sesuai dengan kaidah hukum Faraidh (hukum waris Islam).
